# 수평계 (Bubble Level)

공사 현장에서 쓰는 수평계를 폰으로 옮긴 Android 앱입니다.
수평 기포관, 수직 기포관, 원형 기포를 한 화면에 함께 보여 줍니다.

## 주요 기능

- **한 화면에 세 가지 기포**: 위쪽 수평관(X), 오른쪽 수직관(Y), 왼쪽 원형(X·Y 동시)
- **각도 숫자 표시**: 0.1° 단위 각도와 mm/m(1m당 높이 차이)
- **수평 판정**: 허용 오차 ±0.2° 안에 들어오면 기포관 테두리와 숫자가 연두색으로 바뀌고 "수평"이 표시됨
- **진동 알림**: 수평에 들어설 때 한 번 진동함. 오른쪽 위 종 아이콘으로 켜고 끔
- **영점 보정**: 지금 자세를 0.0°로 맞춤. 보정값은 앱을 다시 켜도 유지되고, "초기화"로 되돌림
- **홀드**: 지금 표시된 값을 고정함
- **종료**: 뒤로 가기를 2초 안에 두 번 누르면 종료되고, 최근 앱 목록에서도 사라짐
- 측정하는 동안 화면이 꺼지지 않고, 세로 화면으로 고정됨

## 사용 방법

| 폰 자세 | 측정하는 축 | 용도 |
|---------|-------------|------|
| 바닥에 눕힘 | X·Y 모두 (원형 사용) | 선반, 바닥, 가구 수평 |
| 세로로 세움 | X (위쪽 수평관) | 벽에 대고 세로 방향 수직(다림추) 확인 |
| 가로로 세움 | Y (오른쪽 수직관) | 액자, 선반 윗면 등 가로 방향 수평 |

- 기포는 실제 수평계처럼 **높은 쪽으로** 움직입니다.
- 지금 자세에서 의미가 없는 축은 숫자 칸에 "—"로 표시합니다.
- 폰 케이스 때문에 오차가 생기면, 평평한 면에 올려놓고 **영점 보정**을 누르세요.

## 동작 원리

중력 센서(`TYPE_GRAVITY`, 없으면 가속도계)가 주는 중력 벡터 `(gx, gy, gz)`로 계산합니다.

- 각 축의 기울기 = `asin(g축 / |g|)`. 그 축이 수평면에서 얼마나 들려 있는지를 나타내는 각도(앙각)라서, 폰을 눕히든 세우든 실제 기포관처럼 동작합니다.
- 중력이 가장 크게 걸린 축을 보고 자세(눕힘 / 세로 / 가로)를 판정하고, 그 자세에서 의미 있는 축만 수평 판정과 영점 보정에 씁니다.
- 숫자가 떨리지 않도록 센서 값에 저역통과 필터(α = 0.1)를 겁니다.
- 수평 판정은 화면에 보이는 0.1° 반올림 값으로 해서, 표시된 숫자와 판정이 항상 일치합니다.
- 진동은 수평에 들어설 때 한 번만 울립니다. 다시 울리려면 허용 오차보다 0.1° 넘게 벗어났다가 돌아와야 해서, 경계에서 진동이 반복되지 않습니다.

## 빌드와 설치

```bash
# 단위 테스트
./gradlew testDebugUnitTest

# 디버그 APK 빌드 → app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleDebug

# USB 디버깅이 켜진 폰에 설치
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`local.properties`에 Android SDK 경로(`sdk.dir`)가 필요합니다. Android Studio로 프로젝트를 열면 자동으로 만들어집니다.

## 프로젝트 구조

```
app/src/main/java/com/bubblelevel/app/
├── MainActivity.kt          # 센서 시작/중지, 화면 꺼짐 방지, 진동, 종료
├── level/
│   ├── LevelMath.kt         # 각도 계산, 자세 판정, 표시 형식, 수평 판정, 진동 트리거
│   ├── GravitySensor.kt     # 중력 센서 + 저역통과 필터
│   └── LevelSettings.kt     # 영점 보정값, 알림 설정 저장 (SharedPreferences)
└── ui/
    ├── LevelScreen.kt       # 통합 화면 (헤더, 숫자 칸, 상태, 버튼, 토스트, 뒤로 가기)
    ├── Vials.kt             # 수평관, 수직관, 원형 기포 그리기 (Canvas)
    ├── LevelIcons.kt        # 선 아이콘
    └── Palette.kt           # 색상
app/src/test/java/com/bubblelevel/app/level/
└── LevelMathTest.kt         # 각도 계산, 표시 형식, 판정 단위 테스트
```

## 참고

- 시스템 글꼴 크기를 키워도 글자가 잘리지 않도록, 글자가 들어가는 칸은 높이를 고정하지 않았습니다.
- 지금은 디버그 APK만 만들 수 있습니다. 릴리스 서명과 스토어 배포는 아직 설정하지 않았습니다.
